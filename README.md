# Eduardo Peixoto — Portfolio

[Leia em português](README.pt-BR.md)

A static, bilingual portfolio presenting Eduardo Peixoto as a founder and software engineer who builds digital products, automation and business systems.

## Homepage structure

The homepage uses seven large content blocks: Hero, Positioning, What I Build, Selected Work, Beyond the Code, GitHub and Contact. GitHub acts as technical evidence; detailed roadmaps and future work remain in the repository documentation.

Selected projects are presented as concise case studies with the problem, solution, stack, visual evidence and learning/result. Current selection: ReadMonitor, Russian Training Hub, edu_assistant and NSA. AI_studies and the remaining experiments remain available through GitHub.

## Visual direction

- `img/eduardo-profile.webp`: primary portrait and professional introduction in the Hero.
- `img/eduardo-editorial.webp`: secondary, contextual portrait in Beyond the Code.
- `img/projects/`: optimised interface screenshots used as project evidence.
- Warm off-white, graphite, deep blue and restrained wine accents.
- Editorial typography, visible dividers and limited card use.
- Subtle hover and viewport interactions with reduced-motion support.

## Technology

HTML5, CSS3 and vanilla JavaScript, with no build step. The site is compatible with GitHub Pages and supports English and Brazilian Portuguese through the lightweight files in `i18n/`.
