# Eduardo Peixoto — Portfólio

[Read in English](README.md)

Portfólio estático e bilíngue que apresenta Eduardo Peixoto como founder e engenheiro de software que constrói produtos digitais, automações e sistemas de negócio.

## Estrutura da homepage

A homepage utiliza sete grandes blocos: Hero, Posicionamento, O que eu construo, Projetos selecionados, Além do código, GitHub e Contato. O GitHub funciona como prova técnica; roadmap e trabalho futuro permanecem na documentação do repositório.

Os projetos selecionados aparecem como estudos de caso concisos com problema, solução, stack, evidência visual e aprendizado/resultado. Seleção atual: ReadMonitor, Russian Training Hub, edu_assistant e NSA. AI_studies e os demais experimentos continuam acessíveis pelo GitHub.

## Direção visual

- `img/eduardo-profile.webp`: retrato principal e apresentação profissional no Hero.
- `img/eduardo-editorial.webp`: retrato secundário e contextual em Além do código.
- `img/projects/`: screenshots otimizados usados como evidência dos projetos.
- Off-white quente, grafite, azul profundo e vinho usado com moderação.
- Tipografia editorial, divisores visíveis e poucos cards.
- Interações sutis com suporte a preferência por movimento reduzido.

## Tecnologia

HTML5, CSS3 e JavaScript puro, sem etapa de build. O site permanece compatível com GitHub Pages e oferece inglês e português brasileiro pelos arquivos leves em `i18n/`.

## Visualização local

```bash
python3 -m http.server 4173
```

Acesse `http://localhost:4173`.
